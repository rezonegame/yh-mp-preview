# 3.19.1：预览优先工作台

日期：2026-10-02。状态：3.19.1-beta.1 本地候选已通过隔离测试与用户验收，按用户授权整理为 3.19.1 稳定版。GitHub 发行和下载核验以 `reports/release-3.19.1-publication.json` 的实际记录为准；官方应用内目录同步未验收。

## 行为与边界

- 依据插件面板的实际宽度／高度切换布局，宽度小于 520 CSS px **或**高度小于 560 CSS px 时使用紧凑工作台。不是按物理屏幕分辨率判断。
- 紧凑模式把“排版设置”和自适应／375px、专注预览入口放在同一行。设置展开为有高度上限的浮层，不挤压正文；点击外部或 Escape 收起。键盘操作中的控件不因尺寸变化被强制隐藏。
- 普通模式直接展示外观控件；“更多工具”仍保留文章操作与局部增强。背景、字体、字号、画廊及全部原有操作继续存在，不迁移配置。
- 底部始终是一行复制与导出。原生 Obsidian 导出菜单保留长图、HTML、分段图三个入口，沿用原有导出适配器、进度与失败处理。
- 检查默认只占一行；用户可展开全部详情，同类问题合并计数并可逐条查看路径。不删除提示，新的阻断问题自动展开且复制仍被禁止。详情高度有限，不占满正文空间。
- 专注预览只临时隐藏设置和非阻断检查区域；阻断提示仍可见。状态不写入配置。正文、Markdown、主题、配方、复制 HTML、导出宽度及笔记增强均保持原契约。
- 只将候选的三个发行文件复制至 `output/refactor/MPPreview-Refactor-Test/.obsidian/plugins/yh-mp-preview`，不运行会重置测试库的准备脚本，不修改 Marketing 库。

## 验证

- `npm run build`：TypeScript 与 JavaScript／CSS 构建通过。
- `npm run verify`：131 项自动测试通过；19 套主题与微信兼容基线核验通过；宿主 lint 0 错误，30 项既有警告。
- 新增 `tests/preview-workspace-runtime.test.mjs`：宽高判定、完整提示分组、阻断优先、折叠状态、专注模式可逆、键盘焦点和监听器清理。
- `scripts/native-preview-workspace.js`：隔离 Obsidian 1.13.7／Windows 下 92 项检查通过，12 组明暗模式与尺寸组合，包括窄面板、矮窗口、设置浮层、原生导出菜单路由、设置与 Markdown 不变、真实阻断问题的复制禁用／恢复，以及专注模式前后导出 HTML／宽高完全相等。
- 原有 `scripts/native-host-regression.js`：28 项通过、1 项明确跳过。长图 1012×13196px；10 张分段图，末段 1012×1046px；HTML 包含头部、尾部和文章末尾。画廊试用／取消、配方幂等、文章切换与源文保持通过。后台运行不能确认系统剪贴板，本轮不宣称真实剪贴板验收。
- 三张实际宿主截图已检查：600×460 浅色、375×700 深色、320×460 深色设置浮层。CLI 首次截图返回上一绘制帧，已拒绝作为证据；使用 `scripts/native-preview-workspace-visuals.js` 双次捕获实际所属 WebContents 后确认画面。汇总与哈希见 `reports/preview-workspace-regression.json`。
- 原生后台窗口会延迟 ResizeObserver。本轮尺寸矩阵显式触发窗口 resize 后调用同一个真实测量路径；浏览器前台、其他操作系统、其他 Obsidian 版本和多种系统 DPI 仍需后续用户验收，不宣称已覆盖。
