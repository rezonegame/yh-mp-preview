# 3.22.0-beta.1 · 框架内配色与阅读密度

这是 P3 的 BRAT 验收候选，不是官方稳定升级。上一稳定与回退点仍为 3.21.0；主分支、官方条目及旧标签不覆盖。仓库和插件 ID 不变：`rezonegame/yh-mp-preview` / `yh-mp-preview`。

## 使用与变化

打开公众号主题画廊，选一套精选升级版，在共享预览下方展开“配色与阅读密度”。每套恰好三种有名称的小色点；不是 42 张新主题卡。密度仅“跟随主题／更紧凑／更舒展”。区域默认折叠，窄／矮窗口可滚动微调区，确认和取消继续可达。

微调影响当前真实文章的预览、复制与导出，主题结构保持；配色按明确强调／浅底／边线角色生成。正文不染品牌色，不改纸底、字号、左右留白、水平缩进、图片比例、表格结构或代码字号。成功／警告等语义色保留。间距倍率 1/.90/1.12，正文行高倍率 1/.96/1.04，最终行高限制 1.65–1.95；只缩放已声明的垂直间距。

点击是试用，只有“应用”才保存。偏好按 `id@revision` 独立记忆；A→B→A 返回 A 已保存的选择，不保留 A 未保存的草稿，也不把 A 的选择带到 B。重置仅当前版式的草稿，不影响字体、背景、局部增强、其他主题或快照。关闭／取消丢弃试用；快照记录并恢复配色、密度、引用和指纹。旧修订、自定义及未来未知数据不自动换色，不在加载时写回。

“当前文章／统一示例”和“正在试用／已保存”只控制画廊显示；已保存对照不改变正在生效的试用输出。手机模式不影响导出 HTML 与宽度。仍需确认应用后才能保存排版快照；复制只处理实际文章，不能复制示例。

## 本机门与限制

正式构建和完整验证、冻结 3.19.1 自动黄金测试、378 个真实手机宽度组合、126 组生产导出快照、114 组同夹具的已验收 3.21.0 旧修订输出对照、隔离库实际保存／重开／重置／快照恢复均需通过后发行。完整证据见 `reports/appearance-tuning-beta1-host.json`；下载资产与 CI 指纹另记。

覆盖 Windows Obsidian 1.13.7 / DPR2、320/375/414 CSS px，浅／暗宿主、代表性 100/125/150% 浏览器缩放、260×360 至 900×700 画廊。缩放不等同于 OS 显示缩放，未测最低宿主与非 Windows。默认纸底普通文字目标 ≥4.5:1 是本项目检查，不是完整 WCAG 认证；自定义复杂背景继续提示无法证明。

HTML、完整长图和分段图实际生成使用代表性微调文章，不宣称每一组合都生成 PNG。系统剪贴板与微信后台仍需用户验收；不绕过后台站点访问限制，不自动发布。原始 Markdown 与隔离库 data.json 最终保持，Marketing 不触碰。来源和历史 MIT／依赖许可继续保留，源码审计不是独立著作来源认证。
