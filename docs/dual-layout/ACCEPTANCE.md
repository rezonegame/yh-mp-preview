### 导出完整性

- [ ] 测试文章包含首、中、尾三个唯一标记。
- [ ] 文章高度超过预览窗口高度至少三倍。
- [ ] 预览滚动到顶部导出长图，三个标记均存在。
- [ ] 预览滚动到中间导出长图，三个标记均存在。
- [ ] 改变窗口高度后重复导出，内容完整。
- [ ] 分段图首段、中段、末段连续，无遗漏或重叠。
- [ ] 末段允许低于 1:1.33 比例，但内容不能截断。

### 资源与失败恢复

- [ ] 正常本地或远程图片导出成功。
- [ ] 失效图片在 10 秒内提示失败，不产生误导性的成功文件。
- [ ] 失败后关闭或重载视图，页面没有 `mp-export-snapshot` 残留。
- [ ] 使用正常文章再次导出成功。
- [ ] 超长文章无法安全生成单张长图时提示使用分段图。
- [ ] 分段失败时显示已完成数量，按钮恢复可用。

### BRAT 与回退

- [ ] `v3.8.3-beta.1` 可以被 BRAT 指定安装。
- [ ] 预发布不会覆盖稳定版本入口。
- [ ] 从 `v3.8.2` 更新到 beta 后插件仍能加载。
- [ ] 回退到 `v3.8.2` 后主题、配方、复制和导出功能正常。
- [ ] 测试库设置和笔记正文没有被意外修改。

结论：待以上项目全部勾选并记录截图或文件证据后，才允许进入 `v3.8.3-rc.1`。
