# 双场景排版宿主兼容说明

## 当前支持边界

- 正式验收平台：Windows。
- Obsidian 阅读视图：使用 Markdown 后处理器，只添加局部类和变量。
- Live Preview：使用 Obsidian 提供的 CodeMirror 6 扩展，不接管输入、选择、撤销或折叠。
- 源码模式：只提供可关闭的标记可读性样式，不改写 Markdown 文本。
- 公众号预览、复制、HTML、长图和分段图：继续使用原有渲染和导出链路。

## 设置与文件生命周期

- 全库和笔记级笔记设置保存在独立的 `note-layout.json`。
- 笔记重命名或移动时，路径覆盖随文件同步。
- 笔记删除时，路径覆盖会被移除。
- 公众号主题选择保存在插件设置，不会写入 `note-layout.json`。
- 主题画廊试用关闭后自动清理临时覆盖。

## 回退方法

1. 先关闭“启用笔记排版增强”，确认阅读视图和实时预览恢复原生。
2. 如需恢复设置，使用“恢复最近的笔记排版设置备份”。
3. 如插件无法加载，通过 BRAT 回退到已知稳定版本；不要删除笔记正文或整个库。

## 未宣称范围

macOS、移动端和非标准第三方编辑器尚未完成真实验收，不在当前版本的正式支持声明内。
