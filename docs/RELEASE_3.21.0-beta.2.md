# 3.21.0-beta.2 引用块手机兼容修复候选

2026-10-03 用户确认升级版主题总体正常，但在微信手机预览发现“深度阅读”引用块左侧出现竖线、右侧延至屏幕边缘。问题未验收通过，因此不发布稳定版。

本地原生证据：旧实现将 border:0 经 Chromium 序列化为部分 initial 边框声明；本地实际左边框为零，不能仅从本地推断远端真正变换原因。新候选逐边写入明确宽度、样式和颜色，并限定引用自动宽度、最大宽度、零水平外边距和 border-box。只增强升级版引用的兼容性，不替换 blockquote 标签，不改嵌套语义、Markdown、旧主题或快照，不增加 AI 或发布功能。

验证：完整构建及 150 项自动测试通过，推荐 lint 零错误、30 警告保留；隔离 Windows Obsidian 1.13.7 中 236 项检查通过，14 套主题 × 320/375/414px × 正常／模拟外部引用默认样式共 84 组合，内外层引用均未超出父级，最外层左右 20px 正文内边距保留。深度阅读及三个同类开放式引用无左右边框，上下横线保留。设置和 Markdown 未改。测试程序见 `scripts/native-reading-quote.js`，证据 `reports/reading-quote-beta2-regression.json`。

限制：模拟 CSS 并非微信真实过滤器。原生图片为最终 canonical 快照的本地渲染，不是实际微信手机截图；本轮没有新增真实系统剪贴板往返、微信后台粘贴保存或完整长图／分段图生成的通过声明。之前 beta.1 的官方数字预检不覆盖本次代码修改。来源审计重跑并保留历史与依赖许可；精确无匹配不证明独立著作来源。

发布范围：只允许通过既有 CI 发布 BRAT 预发行 3.21.0-beta.2；不移动 beta.1 标签，不合并 main、不创建 3.21.0 稳定标签、不更新官方稳定版本。Marketing 库不修改。

用户复验：BRAT 固定此版本，画廊选择深度阅读，点“试用升级版”后应用；重新 Pub 复制到新的后台草稿中，保存并查看微信手机预览。不要只在原草稿上刷新，因为旧粘贴 HTML 仍是旧样式。核对引用无意外左封口、右横线与正文右边界对齐，嵌套和内容完整；通过后再完成其余 P2 验收并准备稳定晋级。
