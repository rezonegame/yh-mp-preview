# 3.21.0-beta.1 · 公众号阅读结构升级

这是新主题版式的 BRAT 测试版，官方稳定渠道仍为 **3.20.0**。

- 十四套精选主题保持七个场景、每个场景两张名称卡片；区别来自标题、引用、列表和图文结构，而非仅换色。
- 原有稿件、旧快照继续使用旧修订。点选卡片试用升级版，小按钮可切回旧版；确认应用之前不保存。
- 六级标题、段落节奏、图注和十种信息组件统一经过安全输出。用户字体、字号、显式背景及留白保留；新版纸底不会在图片导出时被改回白色。
- 当前文章保留局部增强，统一示例不额外增强。新版步骤按每个列表自己的编号显示，不给脚注编号为步骤。
- 自定义背景低对比度／复杂背景给出人工核对提示。保留历史主题、自定义主题、笔记增强、复制、HTML、长图和分段图功能。

本地自动与隔离 Obsidian 测试的具体范围见 `reports/reading-theme-host-regression.json`。Windows 1.13.7 / DPR2；最低宿主、其他系统及完整缩放矩阵未实测。没有加入 AI、图片生成、自动发布、宽表格重排或配色／密度控制。

## BRAT 验收

原地址 `rezonegame/yh-mp-preview`，固定版本 `3.21.0-beta.1`。旧文章打开时外观不应自动改变；点击主题卡片后检查新旧切换、当前文章／统一示例、已保存／试用、取消／保存、字号、背景、复制与全部导出。需要回退可固定 `3.20.0`，旧设置与旧快照不删除。

请将新版主题复制到公众号后台，重点验收长文、教程、报告三篇实际文章和手机预览；十四套主题的后台呈现仍是稳定晋级门。最终宿主回归中，最小 HTML／纯文本剪贴板探针也返回空格式，因此真实剪贴板粘贴记为未验证，未修改复制功能规避该环境问题。此发行不代表公众号实际粘贴已验收，也不代表官方稳定版已升级。
