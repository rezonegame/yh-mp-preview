## 人工验收入口

1. BRAT 为 `rezonegame/yh-mp-preview` 固定 `3.21.0-beta.1`。旧配置默认保留旧版排版；打开画廊、选中主题，点击“试用升级版”，看到“试用升级版”提示后再应用，才能验收本次新样式。
2. 长文、教程、报告各选择一篇自己的文章，逐套检查七个场景的 14 套升级版。文章正文、标题、引用、列表、代码、图片、表格、信息块及文章末尾必须完整；普通宽表格不自动重排。
3. 点击 Pub 复制，粘贴到公众号后台、保存后查看手机预览，记录任何缺失、横向截断、低对比度、过密或过大的间距。此步骤也为真实系统剪贴板往返提供证据；只看本地预览不能代替。
4. 检查升级版／旧版切换、试用取消不保存、应用后保持、已有快照能找回；手机预览切换不改变复制与导出宽度。长图、分段图和 HTML 均核对完整末尾。
5. 反馈说明测试版本、已检查文章和主题、复制／后台保存／手机预览结果。未测项写“未测”，不要仅以本地安装成功视为整阶段验收。
