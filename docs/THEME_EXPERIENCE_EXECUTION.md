### 发现的验证问题与处理

1. 取消重新排版会额外给原始头尾加样式：改成恢复捕获副本，真实 HTML 对照验证。
2. Shadow DOM 缺少宿主根字号／代码换行导致标题偏大及横向溢出：复制展示上下文并补宿主隔离所需代码展示规则；不改变文章输出。
3. ResizeObserver 首次回调会收起用户刚展开的选择区：只在宽／高模式改变时调整展开状态。
4. 原生保存存在节流、后台计时器也会延迟；固定 40/80ms 的测试断言不可靠，一次故障注入的清理又排在未释放假保存之后。修复测试使其等待真实队列／状态并始终释放注入阻塞；未将失败运行计为通过。
5. 发布版本审计要求报告元数据同步：三个既有基线只更新 pluginVersion，样式指纹／兼容发现不变。
