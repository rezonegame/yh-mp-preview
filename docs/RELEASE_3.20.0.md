# 3.20.0 — 已验收的共享主题画廊

`3.20.0-beta.1` 已于 2026-10-03 由维护者确认验收。本版将相同功能提升为稳定版，不混入下一阶段主题重做。

- 在主题画廊直接预览当前文章或本地示例，对照正在试用与已保存效果。
- 大窗口并排展示，窄／矮窗口优先保留文章；名称卡片、场景分类、底部用途与历史小入口继续保留。
- 试用不写设置；取消恢复原效果；保存失败可重试，文章或外观变化使陈旧试用失效。
- 新快照记录主题修订及必要的自定义定义，旧快照仍可使用。

19 套原主题输出保持不变。`3.21.0` 才重做 14 套精选主题的阅读结构，`3.22.0` 才增加精选配色与相对密度；它们尚未包含在本版。

## 更新和回退

原 BRAT 仓库仍为 `rezonegame/yh-mp-preview`。固定测试版的用户可切换到 `3.20.0`。插件 ID、最低 Obsidian 1.7.2 与桌面限定保持不变。

需要回退时，先备份 data.json 和新增快照，再指定 `3.19.1`；不删除配置，不改 Markdown。验收 beta 标签和资产继续保留。
