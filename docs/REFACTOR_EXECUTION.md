## P1 实施内容

1. DOMPurify 在自定义头尾、容器和信息卡进入 DOM 前清洗；对话文本转义、图片协议校验。内联 CSS 单独允许排版属性，拒绝资源加载、转义混淆和旧执行表达式。不安全 HTML、主题或背景资源 CSS会提示；原设置和 Markdown 不改写。
2. 复制在安全 DOM 上处理文本。新增运行测试发现 pangu 的旧 `spacingElement` 已不存在，改用同步 `spacingText` 遍历文本节点，跳过代码；纯文本与清理后的富文本来自同一文章。
3. 静态样式使用 `setCssStyles`，设置标题使用 `Setting.setHeading`，保留折叠状态和作用域样式。无大规模界面重设计。
4. nanoid 固定 `5.1.16`；DOMPurify 固定 `3.4.16`，许可证随发行提供。工具链与锁文件可由 `npm ci` 重建。测试使用 jsdom `26.1.0`：当前 Node 不满足最新版本要求，已试的 27/29 版本对本项目组合 CSS 解析有差异；真实 Chromium 样式检查用于补充，不把 DOM 模拟器当宿主。
5. SDK 固定 `1.8.7`；已对 `1.7.2` SDK 编译核对使用的 API，最低宿主声明改为 `1.7.2`。没有虚称在该旧应用版本中完整运行通过。
6. 新发行使用不带 `v` 的标签，校验仍接受既有 `v` 前缀；插件 ID 不变，旧标签和设置格式不迁移。

## BRAT 人工验收清单（尚待维护者）

指定安装 `3.15.1-beta.1`，先确认 Obsidian >=1.7.2；建议先在测试库验收，并自行备份现有 `data.json`／`note-layout.json`。

1. 重启后能找到并启用插件；主题、隐藏偏好、字体、背景和历史快照仍在。
2. 打开设置，折叠展开和主题画廊可用；试用／取消及375px预览不改写正文或导出宽度。
3. 用长文、教程、报告核对预览及公众号后台复制；正文、标题、引用、列表、代码、图片和信息组件样式正常。
4. 导出 HTML、完整长图、全部分段图，尤其确认文章末尾及图片存在；不把只看窗口截图作为长图验收。
5. 自定义头尾包含安全HTML时样式仍在；不安全输入出现过滤提示且原设置未被改写。CSS `url()` 与 data SVG 不在当前 HTML 安全策略内；若历史稿依赖此类内容，记录差异，不关闭清洗来绕过。
6. 笔记增强正常，编辑空间没有变窄，输入／撤销不受影响。

发现回退先使用 BRAT 指定旧标签 `v3.15.0`（或其版本选择中的3.15.0），无需删除插件配置或正文。本版不改变数据schema。完成真实验收再发布稳定版和进入下一阶段。
