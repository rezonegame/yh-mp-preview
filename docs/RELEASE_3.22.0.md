# 3.22.0 配色与阅读密度稳定升级

将用户已验收的 `3.22.0-beta.1` 整理为稳定版，不混入新运行功能。14 套精选阅读修订各提供原生与两种精选配色，以及“跟随主题／更紧凑／更舒展”密度；入口位于画廊预览下方默认收起的“配色与阅读密度”。主题卡数量和预览优先工作台保持不变。

微调只影响主题强调色、浅底和明确的纵向节奏；保留纸底、正文色、字号、横向缩进、语义状态色和图片比例。点选先试用，确认才按主题 ID／修订保存；取消不写设置，重置只影响当前草稿。返回主题读取各自保存偏好，排版快照保存并恢复完整外观。旧修订、自定义主题和未知未来配置保留兼容路径。

保留全部 19 个主题 ID、历史主题小入口、原仓库、插件 ID、安装路径、Markdown 原文及笔记增强。手机宽度和示例／对照状态不进入复制与导出；不加入 AI、自动发布或新主题卡。已验收的微信引用输出适配保持不变。

## 验收与限制

2026-10-03 用户回复“可以了，你直接发布吧”，接受 P3 候选并授权稳定发布。这是用户报告，不声称智能体访问了微信后台。稳定构建重新运行 154 项自动门，JS/CSS 必须与已验收候选逐字节一致。

候选保留 378 组手机宽度组合、126 组生产快照、实际隔离保存／重开／重置／快照恢复和代表性 HTML／长图／分段图证据。初次性能超预算及夹具不一致运行仍保留，最终公平对照为相对预算通过，不宣称绝对低于 150ms。仅 Windows Obsidian 1.13.7 本机覆盖，其他平台与最低宿主未实测。详见 `reports/appearance-tuning-beta1-host.json`。

## 发布与回退

沿用既有 CI 发布不可变数字标签 `3.22.0`，下载并核验全部 13 个资产，再分别记录官方扫描／公开版本与隔离库原生安装结果。不将 GitHub 发布冒充官方同步或自动更新检测通过。历史来源、许可和来源审计限制保留。

BRAT 固定 beta 的用户可改选稳定 `3.22.0`；回退版本为 `3.21.0`，旧发行和标签不覆盖。Marketing 库不修改。P4 不属于本次稳定晋级。
