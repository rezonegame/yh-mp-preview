## 发行准备与验证

- 官方目录需要与 manifest 版本完全相同、不带 `v` 的发行标签；目前只有 `v3.15.0`，后台尚未识别出匹配的发行。后续修复发布时需调整发行工作流与标签校验，兼顾现有 BRAT 安装。不要移动现有稳定标签或覆盖已验收版本。
- `minAppVersion` 当前为 `0.15.0`；应按实际使用的编辑器与设置 API 核实最低宿主版本，并同步发行兼容性表，不能继续凭旧声明认定兼容。
- 自动检查另报 `nanoid` 依赖风险等非阻断警告，发布前核对并处理适用项。当前安装版本为 `5.1.5`。
- 已补充中英文产品、来源、安装入口和网络行为说明。
- 每次功能代码修复后运行 `npm run verify`，补充对应安全／回归测试，再在官方后台触发审核。文档调整本身不代表技术问题已经解决。
- 真实宿主验证至少覆盖加载、设置页、主题画廊、笔记增强、复制 HTML、长图和分段图，确保公众号内联样式未被清洗或丢失。来源问题与技术问题都解决后才能 Publish。
