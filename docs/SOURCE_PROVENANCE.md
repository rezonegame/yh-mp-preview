## 固定比较范围与复现

- 上游：`Yeban8090/mp-preview` 固定提交 `49e77aabd62b7c01a812a10e457cf7a12e45199e`。

- 整文件比较：二进制逐字节，文本只归一化 CRLF／LF；跨路径查找。
- TypeScript：忽略空白与注释但保留标识符／字面量；比较具名方法体 ≥60 token 和连续片段 ≥80 token。
- CSS：比较选择器与声明，忽略空白／注释，声明长度 ≥60 字符。
