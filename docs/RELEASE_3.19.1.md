# 3.19.1 — 预览优先与宽高自适应

## 本次更新

- 按插件面板的实际宽度和高度切换布局，窄／矮窗口主要显示正文预览。
- 排版设置按需展开为有高度上限的浮层；增加临时“专注预览”，不保存为文章设置。
- 兼容性检查默认显示一行，可展开完整详情；同类提示合并计数，保留每条路径。阻断问题仍会提示并禁止复制。
- 底部改为“Pub 复制＋导出菜单”，长图、HTML 和分段图全部保留。
- 不修改 Markdown、主题／配方 ID、现有设置、笔记增强或复制／导出尺寸契约。

## 验证与验收

开发候选通过 131 项自动测试、92 项真实宿主布局检查；已检查明暗模式与 12 组面板尺寸，以及三张实际宿主截图。导出回归有 28 项通过、1 项后台剪贴板跳过：长图 1012×13196px，10 张分段图，HTML 包含文章末尾。宿主 lint 0 错误，30 项既有警告。

用户已确认测试无问题并授权发布。稳定版只同步版本与记录，JavaScript／CSS 与最终验收候选字节一致。没有宣称完成其他操作系统、所有 DPI、旧宿主版本或应用内目录安装验收。
