# 3.20.0-beta.1 — 共享主题画廊预览

这是主题体验升级计划的 P0/P1 测试版，不是官方稳定更新。原仓库、插件 ID 与现有笔记保持不变；稳定版继续为 3.19.1。

## 本次变化

- 主题画廊直接展示当前文章，也可切换自带本地示例，无需反复关闭画廊查看效果。
- 可对照“正在试用”和“已保存”的效果；试用、取消与保存分别处理，不把草稿写入设置。
- 保留按场景选择、仅显示名称的卡片及底部用途说明；历史主题仍通过小入口找回。
- 大窗口并排显示选择与预览；窄窗口可收起选择区，优先保留正文预览，操作按钮保持可达。
- 保存失败可重试；文章或外观配置发生变化时使陈旧试用失效；快照保留主题引用与自定义定义。
- 优化共享预览的图片复用与资源清理，避免每次主题试用都重新解析图片源。

本版不重做主题样式。19 个主题 ID 保留，114 组真实 Obsidian 主题／配方输出与 3.19.1 完全一致。下一阶段的主题结构、配色与阅读密度升级，须在本版验收后分别推进。

## 安装与验收

在 BRAT 中使用原仓库 `rezonegame/yh-mp-preview`，指定版本 **`3.20.0-beta.1`**。仅点击默认最新稳定版本可能仍得到 3.19.1。

建议先在测试库体验，确认以下流程：

1. 打开主题画廊，在当前文章与本地示例之间切换。
2. 试用不同主题，对照已保存效果，然后取消；原文章效果应恢复。
3. 重新试用并保存，关闭后确认主预览、复制与导出保持一致。
4. 将面板缩窄，检查选择区、正文与底部按钮；再试用隐藏／历史主题。

需要回退时，先备份插件 data.json，再用 BRAT 指定 3.19.1；不要直接删除配置文件。

- 19 × 6 组真实旧主题／配方输出哈希保持一致，测试源文与配置字节未变。
- 浅／暗界面十组尺寸检查覆盖 260×360 至 900×700；完整文章 HTML、长图与分段图回归通过。
- 发行安装三文件重新下载后，与已测试本地产物 SHA-256 完全一致；许可证和来源声明随包保留。
