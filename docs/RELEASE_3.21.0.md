# 3.21.0 手机阅读主题稳定升级

将用户完整验收的 `3.21.0-beta.3` 整理为稳定版，不新增运行功能。14 套精选主题按七种场景提供两套不同的阅读结构，升级标题、引用、列表、图注和信息组件，保留字号、背景及手机安全规则。

深度阅读等升级主题的复制与导出引用采用普通排版容器，避开微信原生引用灰条；本地 Markdown 和引用语义保持。HTML、长图、分段图共用规范化输出，手机预览宽度不改变导出宽度。

已有稿件和快照继续使用保存的旧修订；在画廊选中主题并确认应用升级版后才切换。保留全部 19 个 ID、旧版定义、历史主题小入口、自定义主题及可选笔记增强。不修改 Markdown，不加入 AI、自动发布或配色／密度设置。原仓库、插件 ID 与安装路径不变。

## 验收依据

2026-10-03 用户先确认 beta.3 引用修复无问题；在明确询问长文、教程、报告三类文章及其他主题的复制／后台保存／手机预览后，回复“都测试过了”。记录为完整 P2 用户验收，不声称智能体访问了微信后台。

稳定构建需与验收候选 JS/CSS 逐字节一致，并重跑 151 项自动门。候选原生证据保留：348 项手机引用检查、508 项输出检查、84 组主题／配方生产快照，代表性实际 HTML／长图／分段图生成。Windows Obsidian 1.13.7；其他系统及最低宿主未实测。候选的本地剪贴板探针失败仍保留，不将用户成功粘贴改写成智能体探针通过。未额外修改正文粗细，用户验收不表示逐像素跨设备一致。
